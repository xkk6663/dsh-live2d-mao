## 1. 优先级 A：值得做（成本可控、收益明确）

### A1. `mao-pet` 插件发布到 npm（Phase 4 收尾）

**为什么**：现在装插件只能用 `dsh plugin add link:<本地绝对路径>`。发布后用户 `dsh plugin add mao-pet` 一键装，这是「插件化」定位的最后一公里。

**要做**：
- [ ] `package.json` 去掉 `private: true`，补 `repository` / `homepage` / `keywords`（已有关键词）
- [ ] 加 `icon.png`（256×256 正方形含透明，DSH 插件列表读它）
- [ ] 写 `packages/mao-pet/README.md`（装法/能力/排障）
- [ ] 写 `PROVENANCE.md`（素材许可如实标注，参照 whale 做法）
- [ ] `npm publish --dry-run` 校验 files 清单不含多余文件
- [ ] 发布后更新 `AGENTS.md` / `README.md` 的安装说明

**风险**：npm 包名 `mao-pet` 是否被占——发布前先 `npm view mao-pet` 查。

### A2. 上下文压力 / 用量投影接 UI（`projections.js` 已就绪但没人消费）

**为什么**：`lib/projections.js` 已能读 `contextPressure`（上下文占比）、`tokenUsage`、`inbox`，且有完整测试，**但没有 UI 消费它**（本轮已把死包装函数删掉，模块保留）。

**价值**：DSH 用户很关心「上下文还剩多少」——这是 DSH 界面上就有、但桌宠能「一直看得见」的信息。

**要做**：
- [ ] 插件侧把 `summarizeAll(projectionService, session)` 的结果挂到 `pushPhase` 的 `state` 里（state 已经是白名单收敛的，加 `ctx_pressure` / `tokens` 字段）
- [ ] 后端 `_sanitize_state` 白名单放行这两个字段
- [ ] 桌宠侧：横条或徽标显示「上下文 62%」（建议放徽标 tooltip，不占横条文字）

**成本**：小（数据链路现成，只差最后一跳 + 展示）。

### A3. 真实 DSH 会话下的端到端回归脚本

**为什么**：现在的 E2E 是「注入 WS 桩」测渲染端，adapter 自检测协议层，但**没有一条「真 DSH 会话 → 真实桌宠窗口」的自动回归**。每次改完只能靠人工看。

**要做**：
- [ ] 一个脚本：起一段真实 DSH 会话（或回放 fixture）→ 轮询 `/api/companion/agents` 断言 phase 序列 → 断言横条内容
- [ ] 挂在门禁里（可选，耗时长）

## 3. 明确不做（已裁决，别翻案）

| 项 | 裁决理由 |
|---|---|
| **余额记账** | 用户裁决：「要填 API key 的就不做了」。whale 能读余额是因为它跑在 DSH 进程内、直接读 DSH 凭据；我们的独立后端读不到 ⇒ 只能逼用户再填一份 key，违背「轻量化 + 插件化」定位 |
| **审批/提问回传** | DSH 审批策略是 `never` 时从不触发；需要审批时直接开 DSH 界面更快，从桌宠点按钮属绕远路。已阉割三端代码 |
| **TTS / 语音合成** | 裁决 D1：不引入 TTS 依赖。`voice` phase 保留为预留插座 |
| **多 Agent（小智/Octop）** | 既有裁决：DSH 专用仓库，两插件已整体阉割 |
| **陪伴型功能**（天气/歌词/报时/每日一签/待办） | 偏离「DSH 工作状态的脸」定位；留给 dsh-pet-indesktop 那类「陪伴型桌宠」 |

## 4. 已知技术债（不影响功能，但值得知道）

| 项 | 说明 |
|---|---|
| **横条 Markdown 是极简实现** | 只支持代码药丸 / `**粗体**` / 行首 `#`。**刻意不做斜体**（会误伤 `3*4`）、链接、图片、列表——横条空间小，完整 Markdown 交给 DSH 界面 |
| **不透明度靠 Cubism renderer 的 `setModelColor`** | 不是 PIXI 的 `alpha`（对 Cubism 无效）。两次修才走通，源码级证据见 `live2d-pet.js` 的 `applyPetOpacity` 注释。**换渲染库时要重新验** |
| **管理窗 localStorage 不持久** | `main.js:219` 每次创建都 `clearStorageData()`。任何「管理窗侧的用户偏好」**必须存后端 settings**，别存 localStorage（12 态颜色已因此改存后端） |
| **`dist/` 是半手写半构建** | `core-inject`/`kernel`/`plugins`/`live2d-pet` 是手写层（改直接改 + 升 `?v=`），`assets` 是 Vite 产物。见 `AGENTS.md` §4 |
| **插件路由白名单是硬断言** | `dsh_adapter_selftest.py` 里有「暴露哪些端点」的逐条白名单，**新增/删除端点必须同步改那两条断言**，否则自检红 |
| **设置项三处登记** | 新增 `live2d_*` 设置键必须同时改：`routes/companion.py` 白名单 + `companion_service.py` DEFAULT_CONFIG + 前端 `settingsKeys`。漏一处 = 「保存无效」 |
