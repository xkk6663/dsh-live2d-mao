## 3. 明确不做（已裁决，别翻案）

| 项 | 裁决理由 |
|---|---|
| **余额记账** | 用户裁决：「要填 API key 的就不做了」。whale 能读余额是因为它跑在 DSH 进程内、直接读 DSH 凭据；我们的独立后端读不到 ⇒ 只能逼用户再填一份 key，违背「轻量化 + 插件化」定位 |
| **审批/提问回传** | DSH 审批策略是 `never` 时从不触发；需要审批时直接开 DSH 界面更快，从桌宠点按钮属绕远路。已阉割三端代码 |
| **TTS / 语音合成** | 裁决 D1：不引入 TTS 依赖。`voice` phase 保留为预留插座 |
| **多 Agent（小智/Octop）** | 既有裁决：DSH 专用仓库，两插件已整体阉割 |
| **陪伴型功能**（天气/歌词/报时/每日一签/待办） | 偏离「DSH 工作状态的脸」定位；留给 dsh-pet-indesktop 那类「陪伴型桌宠」 |

## 4. 已知技术债（不影响功能，但值得知道）

| 项 | 说明 |
|---|---|
| **横条 Markdown 是极简实现** | 只支持代码药丸 / `**粗体**` / 行首 `#`。**刻意不做斜体**（会误伤 `3*4`）、链接、图片、列表——横条空间小，完整 Markdown 交给 DSH 界面 |
| **不透明度靠 Cubism renderer 的 `setModelColor`** | 不是 PIXI 的 `alpha`（对 Cubism 无效）。两次修才走通，源码级证据见 `live2d-pet.js` 的 `applyPetOpacity` 注释。**换渲染库时要重新验** |
| **管理窗 localStorage 不持久** | `main.js:219` 每次创建都 `clearStorageData()`。任何「管理窗侧的用户偏好」**必须存后端 settings**，别存 localStorage（12 态颜色已因此改存后端） |
| **`dist/` 是半手写半构建** | `core-inject`/`kernel`/`plugins`/`live2d-pet` 是手写层（改直接改 + 升 `?v=`），`assets` 是 Vite 产物。见 `AGENTS.md` §4 |
| **插件路由白名单是硬断言** | `dsh_adapter_selftest.py` 里有「暴露哪些端点」的逐条白名单，**新增/删除端点必须同步改那两条断言**，否则自检红 |
| **设置项三处登记** | 新增 `live2d_*` 设置键必须同时改：`routes/companion.py` 白名单 + `companion_service.py` DEFAULT_CONFIG + 前端 `settingsKeys`。漏一处 = 「保存无效」 |
