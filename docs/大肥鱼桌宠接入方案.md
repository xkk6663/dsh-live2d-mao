# 大肥鱼桌宠接入方案

> 让本地桌宠接入云端 AstrBot 的大肥鱼 persona，实现微信、桌宠等多设备共享同一人格与记忆。

---

## 架构总览

```
┌─────────────┐     SSE/HTTP      ┌─────────────────┐
│  本地桌宠    │ ◄──────────────► │  云端 AstrBot    │
│  (Windows)   │    Open API       │  (阿里云 ECS)    │
│             │                   │                 │
│  pet-chat   │                   │  persona: 333   │
│  bar UI     │                   │  livingmemory   │
│  +后端      │                   │  微信平台        │
└─────────────┘                   └─────────────────┘
```

**核心原理**：本地 companion 后端新增 `cloud_feiyu` provider，选这个模型时不走本地 LLM，直接调云端 AstrBot Open API。通过复用微信会话的 `session_id`，实现短期记忆 + 长期记忆完全共享。

---

## 已实现能力

### 1. 文字对话 ✅
- 桌宠发文字 → 大肥鱼回复文字 → 桌宠气泡显示
- 大肥鱼傲娇人设完整保留（persona 333）
- 回复自动走现有 TTS 朗读

### 2. 记忆共享 ✅
- 桌宠和微信用同一个 `session_id`（微信会话的 conversation_id）
- 短期对话历史：共享
- 长期记忆（livingmemory）：共享
- 大肥鱼在微信里聊过的内容，桌宠里继续聊她记得
- 问她"我们在微信聊了什么"，她能答上来

### 3. 图片互传 ✅
- 桌宠发图片给大肥鱼：支持（base64 data URL）
- 大肥鱼回图片给桌宠：SSE 解析支持图片段（omnidraw 文生图）

### 4. 设备上下文注入 ✅
- 每次发消息自动附加设备状态：
  - 当前设备名、操作系统
  - 当前时间
  - 可用工具清单
- 大肥鱼"知道"自己现在在桌宠上

### 5. 语音朗读 ✅
- 大肥鱼回复文字后，桌宠自动走 edge-tts 朗读
- 和现有 companion 语音逻辑完全一致

### 6. 表情标记解析 ✅
- 自动解析 `&&happy&&`、`&&affection&&` 等标记
- 转换成桌宠对应情绪状态

### 7. MCP 工具端点 ✅
- 本地暴露 `/api/feiyu/mcp/tools` — 列出可用工具
- 本地暴露 `/api/feiyu/mcp/call` — 调用工具
- 内置工具：`get_dsh_status`、`get_system_info`
- 后续可升级为标准 MCP server，让云端 AstrBot 直接连接

### 8. API 安全 ✅
- API Key scope 最小化：只有 chat/im/file，没有 config 权限
- 不主动调用：只有用户在桌宠发消息时才调 API，没有后台轮询
- 不吃 token：无定时任务、无自动触发
- 工具调用需显式触发，大肥鱼不能随便调本地能力

### 9. 流式气泡 ✅
- 大肥鱼回复逐字推到桌宠气泡（`stream_text` WS 事件）
- 和 DSH 工作信息（横条）完全分开
- DSH 状态走 `pet-strip`，大肥鱼对话走 `speech-bubble`

### 10. 设备在线状态 ✅
- 桌宠启动时自动通知云端："电脑桌宠已上线"
- 大肥鱼在微信里也能知道哪些设备在线
- MCP 工具 `get_online_devices` 可查询在线设备列表
- 当前在线设备：手机微信、电脑桌宠

## 配置说明

### 环境变量（后端启动前设置）

```powershell
# 必填
$env:ASTRBOT_API_KEY = "abk_***REDACTED***"

# 可选（有默认值）
$env:ASTRBOT_BASE_URL = "http://<云端地址>:6185"
$env:ASTRBOT_USERNAME = "xiao1"
$env:ASTRBOT_PLATFORM = "mao-pet"
$env:ASTRBOT_SESSION_ID = "d93c5ca6-c3d8-47a0-a9ea-124334bcde70"  # 微信会话 ID
```

### 模型选择

在 companion 设置里把 `pet_chat_model_id` 设为：
```
cloud_feiyu
```

或者聊天时手动指定 `model_id: "cloud_feiyu"`。

## API 参考

### AstrBot Open API 端点

| 端点 | 用途 |
|---|---|
| `POST :6185/api/v1/chat` | 发消息（SSE 流式返回） |
| `WS :6185/api/v1/chat/ws` | WebSocket 聊天桥 |
| `GET /api/v1/chat/sessions` | 会话列表 |

### 认证
```
Authorization: Bearer abk_xxxxx
```

### 请求示例
```json
{
  "message": [
    {"type": "text", "text": "你好"}
  ],
  "session_id": "d93c5ca6-c3d8-47a0-a9ea-124334bcde70",
  "username": "xiao1",
  "platform_id": "mao-pet",
  "enable_streaming": false
}
```

### 返回格式（SSE）
```
data: {"type": "session_id", "data": null, "session_id": "..."}
data: {"type": "user_message_saved", "data": {...}}
data: {"type": "run_started", "data": {...}}
data: {"type": "plain", "data": "哼，桌宠？", "streaming": false}
```
